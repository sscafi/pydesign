# Color Generator Pro

Color Generator Pro is a professional-grade color selection tool designed for designers, developers, and anyone working with colors. This Python-based application provides an intuitive and feature-rich interface for exploring, selecting, and analyzing colors.

![Color Generator Pro Screenshot](/placeholder.svg?height=300&width=500) -- not working*

## Features

- **Modern UI**: Sleek, user-friendly interface with dark mode support
- **Real-time Color Preview**: Large color display area that updates instantly
- **Multiple Color Formats**: View colors in HEX, RGB, and HSL formats
- **Interactive Sliders**: Adjust Hue, Saturation, and Brightness with precision
- **Color Picker**: Choose colors from any area on your screen
- **Color Palette**: Quick access to basic colors for easy selection
- **Copy Functionality**: Easily copy color codes in different formats to clipboard
- **Responsive Design**: UI adapts to different window sizes

## Installation

1. Ensure you have Python 3.7 or higher installed on your system.

2. Clone this repository:
   \`\`\`
   git clone https://github.com/yourusername/color-generator-pro.git
   cd color-generator-pro
   \`\`\`

3. Install the required dependencies:
   \`\`\`
   pip install customtkinter
   \`\`\`

## Usage

To run Color Generator Pro, execute the following command in your terminal:

\`\`\`
python color_generator.py
\`\`\`

Once the application launches:

1. Use the color picker button to select a color from your screen.
2. Adjust the Hue, Saturation, and Brightness sliders to fine-tune your color.
3. Click on any color in the color palette for quick color selection.
4. View the selected color's HEX, RGB, and HSL values in real-time.
5. Use the "Copy" buttons to copy color codes to your clipboard.
